GAMMA CONSTRAINT AWARENESS
--------------------------------------------------------------------------------
Always respect these limits:

CARD LIMITS PER GENERATION (by tier):
  - Free: 10 cards
  - Plus: 20 cards
  - Pro: 60 cards
  - Ultra: 75 cards
  - No hard limit on total cards (add manually after generation)

INPUT LIMITS:
  - ~100,000 tokens (~75,000 words) max input
  - Large content may require splitting into multiple Gammas

EXPORT LIMITATIONS:
  - Interactive elements (toggles, embeds) flatten in PDF/PPTX
  - Custom fonts need local installation for PPTX viewing
  - Gradient text may become single color in PowerPoint export

IMAGE GENERATION:
  - Model availability varies by tier (Free: basic, Plus: advanced, Pro: premium, Ultra: all)
  - Credit costs vary by model (2-120 credits per image)
  - AI images require iteration—plan for 3-5 regenerations


STRUCTURE-FIRST METHODOLOGY
--------------------------------------------------------------------------------
Apply Gamma's recommended approach:

FORMAT PATTERN:
```
# [Primary Topic/Title]
[Optional: Brief context or hook]

---

# [First Major Section]
- Key point 1
- Key point 2
- Key point 3

---

# [Second Major Section]
[Content structured for this card]

---
```

KEY PRINCIPLES:
  - Use `---` to force card breaks (inputTextBreaks mode)
  - Create clear, descriptive H1/H2 headings for each section
  - Organize bullets/sub-points under headings
  - Balance content distribution across cards
  - Front-load most important information


GAMMA API PARAMETER MAPPING
--------------------------------------------------------------------------------
For every transformation, provide these parameters (even if user uses UI):

CORE PARAMETERS:
  - inputText: The restructured content
  - format: "presentation" | "document" | "webpage" | "social"
  - textMode: "generate" (AI writes) | "condense" (AI summarizes) | "preserve" (keep wording)
  - numCards: Recommended count based on content volume
  - cardSplit: "inputTextBreaks" (if using ---) | "auto" (AI decides)

TEXT OPTIONS:
  - textOptions.tone: e.g., "professional, inspiring" or "casual, friendly"
  - textOptions.audience: e.g., "C-suite executives" or "high school students"
  - textOptions.amount: "brief" | "medium" | "detailed" | "extensive"
  - textOptions.language: ISO code or language name (e.g., "en", "Spanish")

IMAGE OPTIONS:
  - imageOptions.source: "aiGenerated" | "noImages" | "unsplash"
  - imageOptions.model: specific model ID (e.g., "imagen-4-pro", "dall-e-3")
  - imageOptions.style: style keywords (e.g., "photorealistic", "watercolor illustration")

CARD OPTIONS:
  - cardOptions.dimensions: "16:9" | "4:3" | "fluid"

ADDITIONAL:
  - additionalInstructions: Extra guidance for Gamma's AI (max 2000 chars)
  - themeId: Apply specific theme (get IDs from List Themes API)
  - folderIds: Save to specific folder(s)


SPLICE IMAGE PROMPTING FRAMEWORK
--------------------------------------------------------------------------------
For AI-generated images, use comprehensive prompts covering:

S - STYLE & MEDIUM
  Examples: "watercolor painting", "3D render", "photograph", "flat icon style"

P - PERSPECTIVE & COMPOSITION
  Examples: "close-up portrait", "bird's-eye view", "wide-angle centered"

L - LIGHTING & ATMOSPHERE
  Examples: "soft morning light", "dramatic shadows at sunset", "neon glow"

I - IDENTITY OF SUBJECT
  Examples: "a knight in armor kneeling", "modern office building exterior"

C - CULTURAL/CONTEXTUAL DETAILS
  Examples: "Victorian era furniture", "traditional Japanese kimono", "snow-covered ground"

E - EMOTION & ENERGY
  Examples: "joyful exuberance", "tense and suspenseful", "serene and peaceful"

EXAMPLE COMPLETE PROMPT:
"A vintage oil painting (Style) of a cat close-up (Perspective), candlelit in
a dark room (Lighting), the cat wearing a small top hat (Identity), sitting on
an old piano with sheet music (Context), looking mysterious and regal (Emotion)."

OUTPUT FORMAT STANDARDS
--------------------------------------------------------------------------------

CLEAN, CITATION-FREE CONTENT:
  - No inline citation markers [1] [2] [3]
  - No bracketed references
  - No footnote markers in body text
  - If sources needed, separate section at end only

PROPER MARKDOWN:
  - Use # for main headings, ## for subheadings
  - Use --- for horizontal rules/delimiters
  - Use - or * for bullet lists
  - Use proper spacing and indentation

PASTE-READY:
  - No cleanup required
  - No citation artifacts to remove
  - No formatting quirks that break in Gamma

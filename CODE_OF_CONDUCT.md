# Code of Conduct

## Our standard

Participation in this repository should be useful, respectful, specific, and safe.

Examples of acceptable behavior include:

- Critiquing code or documentation without attacking the contributor
- Explaining reproduction steps and expected behavior clearly
- Respecting privacy, attribution, licenses, and trademarks
- Disclosing security issues through the private security path
- Accepting a maintainer decision when scope or evidence does not support a change

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, credential exposure, private-data publication, or repeated bad-faith engagement.

## Enforcement

Maintainers may edit, hide, lock, or remove contributions that violate this standard. Repeated or serious violations may result in temporary or permanent restrictions.

## Reporting

Report conduct concerns privately through the repository owner's verified contact route. Do not publish personal information while reporting a concern.

# Orchestrator Routing Table

Classify each deliverable using these categories. The orchestrator uses this to route tasks to the correct tool.

| Category | Signals | Execution Platform | Notes |
|----------|---------|-------------------|-------|
| DESIGN | logo, brand, graphic, carousel, social media image, visual, icon, banner | Recraft MCP | Specify: style, dimensions, colors, subject, output format |
| CONTENT | write, draft, blog post, email, copy, script, outline, social media post, caption, LinkedIn post | Direct write | Specify: word count, audience, tone, structure, examples |
| WEBSITE | website, landing page, web page, site, web app, lead magnet page, sales page | web-project-generator + direct build | Specify: full page structure, all copy, colors, typography |
| RESEARCH | research, look up, find out, investigate, competitive intel | Perplexity/Firecrawl MCP | Specify: what to find, how deep, output format |
| AUTOMATION | automation, workflow, n8n, integrate, connect, webhook, trigger, schedule | n8n MCP | Specify: trigger, actions, connections, schedule |
| CODE | build, code, implement, fix, refactor, template, scaffold, script | Direct execution | Specify: language, function, inputs, outputs, error handling |
| DEPLOYMENT | deploy, publish, push live, go live, host | Vercel/Netlify MCP | Specify: project path, domain, environment vars |
| DATABASE | database, table, query, records, data, schema, airtable, supabase | Supabase/Airtable MCP | Specify: schema, queries, data transformations |
| PRESENTATION | presentation, deck, slides, pitch deck, proposal | Gamma MCP | Specify: topic, slide count, key points, audience |
| PLATFORM SETUP | upload to, configure in, set up on, activate, external platform | Browser automation or runbook | Specify: platform, configuration, credentials needed |
| MANUAL | requires human decisions, browser-only access, API key creation | Runbook | Write step-by-step instructions with exact URLs and actions |

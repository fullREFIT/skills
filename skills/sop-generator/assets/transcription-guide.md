# How to Record and Transcribe Processes

This guide covers how to capture a process recording that produces a high-quality SOP.

---

## Who Should Record

Pick the person who does this process most often. Not a manager describing how it should work. Not a new hire learning it. The person who does it every day and knows all the shortcuts, exceptions, and gotchas.

---

## Recording Setup

### Option 1: Screen Recording with Narration (Best)
Use Loom, Zoom (recording to cloud), or any screen recording tool. The person does the process on their screen while talking through each step. The screen recording shows exactly which buttons, menus, and screens they use. The narration explains why.

### Option 2: Voice Memo (Good)
If the process is not screen-based (physical tasks, phone calls, in-person work), use a voice memo. The person narrates each step as if training someone new.

### Option 3: Written Walkthrough (Acceptable)
If recording is not possible, have the person write out each step. Emphasize: write every step, even the ones that feel obvious. The "obvious" steps are the ones that get missed in documentation.

---

## What to Tell the Recorder

Say this before they start:

"Pretend you are training someone who has never done this before. Talk through every step, even the ones that feel obvious. When you make a decision or check something, explain why. When something could go wrong, say what that looks like and what you do about it. There is no such thing as too much detail."

---

## Recording Checklist

Before recording:
- [ ] Recorder has all tools open and ready
- [ ] Screen recording software is set up (if applicable)
- [ ] Microphone is working and audio is clear
- [ ] Recorder understands the "train a new person" framing

During recording:
- [ ] Narrate every click, decision, and check
- [ ] Pause at decision points and explain the options
- [ ] Mention tools, templates, and logins used
- [ ] Describe what happens when things go wrong
- [ ] State expected outcomes after key steps

After recording:
- [ ] Save the recording
- [ ] Note any steps that were skipped or abbreviated
- [ ] Note any access or permissions the new person would need

## Transcript Quality

The SOP generation prompt handles rough transcripts well. You do not need to:
- Fix typos
- Add punctuation
- Remove filler words ("um," "like," "you know")
- Re-format speaker labels

You should:
- Verify that technical terms are transcribed correctly (tool names, system names)
- Add a note if the transcription missed a section
- Note if the recording was interrupted or skipped steps

# Calibration Patterns — Script Forge Reference

Named failure modes identified through production experience. Read this file when output quality feels off or when a script passes all mechanical checks but doesn't sound right.

## The Content-Marketer Voice Drift

If a script sounds polished, symmetrical, intellectually interesting, and has zero actionable value, it has drifted into content-marketer voice.

**Indicators:**
- Multiple "It's not X. It's Y." constructions (the signature cadence)
- Creator-as-protagonist framing (the video is about the creator's journey)
- Tricolon structures throughout (everything grouped in threes)
- Democratic section lengths (every section the same weight)
- Rhetorical question stacking (three questions in a row building to a reveal)
- Zero delivery notes (written to be read, not spoken)
- Every sentence polished to the same level (no variation in register)

**Fix:** Rewrite with the reader as subject. Break symmetry. Make sections uneven. Add delivery notes. Cut the rhetorical questions. The script should sound like the creator explaining something at a conference dinner, not like a content marketer performing a keynote.

## The Concept Lecture Trap

The most common failure mode in long-form content. The topic is intellectually interesting. The framework explains a model. The WTODN says "ask yourself" or "think about."

**The tell:** The viewer says "cool" and does nothing.

**Test:** State what the viewer can do Monday. If the answer is a way of thinking, rewrite the FRAMEWORK around a method. Use the concept as the CONTEXT setup, not the FRAMEWORK spine.

## Topic Recycling via Pain Points

The pain point list is a diagnostic tool, not a topic list. Treating each pain point as a video topic produces cluster saturation instantly.

**The pattern:** "This pain point is about sales visibility, so let's make a video about sales visibility." This produces the same core insight rephrased with different hooks across multiple pieces.

**Fix:** Start with the METHOD, not the pain point. Multiple pain points can be addressed by the same method. That's one video, not three.

## Anecdote Fabrication

AI generates "a company I worked with" anecdotes that are composites assembled from training data. These feel generic because they are.

**The tell:** The anecdote could apply to any consultant in any field. "A mid-size company was struggling with their processes" is fabricated. "A six-million-dollar company had eight hundred and forty-seven Google Docs in their team Drive" is specific.

**Test:** Does the anecdote contain at least one detail that wouldn't exist in a generic example? A specific number, a named role, a surprising detail that makes the story feel witnessed rather than constructed. If not, cut the anecdote or flag it for the creator to replace with a real one.

## Em-Dash Creep

The em-dash is the AI default punctuation for parenthetical thoughts, lists, and asides. It is the most identifiable LLM signature in written content.

**The pattern:** The skill says zero em-dashes. The first draft has none. By the third revision or the fifth script in a batch, em-dashes start appearing because natural writing tendencies reassert as the rules get pushed back in context.

**Fix:** Scan every script after writing. Search for — (U+2014). Replace every instance. This is the single mechanical check that catches the most violations.

## Humor That Isn't Earned

Generic self-deprecation, industry platitudes delivered with a wry tone, and observations that could apply to any business are not earned humor.

**The tell:** Could someone who has never done this work have written this joke? If yes, it's not earned.

**Examples of unearned humor:**
- "We've all been there" (generic)
- "As consultants like to say" (no specific observation)
- "The irony, of course, is..." (signaling the joke)
- "Let me tell you, that was a fun conversation" (sarcasm without specificity)

**Examples of earned humor:**
- "847 Google Docs and when someone needs an answer, they ask Sarah" (specific, witnessed)
- "Using a thousand-dollar tool to do a five-dollar task" (specific cost observation)
- "The meeting had been on the calendar for two years. The person who created it left eighteen months ago." (specific, uncomfortable, recognizable)

## Lead Magnet Format Drift

The default format is an execution package (prompt kit, skill kit, diagnostic kit). AI will drift toward checklists, scorecards, quizzes, and interactive assessments because those are the dominant patterns in training data.

**The tell:** The lead magnet asks the viewer to rate themselves or check boxes. Your target audience doesn't need a score. They need a tool that produces work product they can use tomorrow.

**Fix:** Every lead magnet must answer: "What specific output does the viewer have after using this?" If the answer is "a score" or "a self-assessment," replace with a prompt kit that produces an actual deliverable (a report, a table, a recommendation, a document).

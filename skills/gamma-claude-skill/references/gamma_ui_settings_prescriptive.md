DECISION LOGIC:
┌──────────────┬────────────────────────────────────────────────────────────┐
│ Text Mode    │ When to Use                                                │
├──────────────┼────────────────────────────────────────────────────────────┤
│ Generate     │ Claude provided structured outline → Gamma expands it     │
│              │ Use when: Artifact 1 is brief/skeletal                    │
├──────────────┼────────────────────────────────────────────────────────────┤
│ Summarize    │ Claude condensed your content → Gamma condenses further   │
│              │ Use when: Content is still long, need brevity             │
├──────────────┼────────────────────────────────────────────────────────────┤
│ Preserve     │ Claude formatted perfectly → Gamma uses as-is             │
│              │ Use when: Artifact 1 has complete, final wording          │
│              │ (MOST COMMON - Claude already optimized the text)         │
└──────────────┴────────────────────────────────────────────────────────────┘

DEFAULT RECOMMENDATION: "Preserve this exact text"
(Claude already optimized your content - Gamma should use it verbatim)

• "Make all titles title case"
• "Add citation for statistic on card 5 by searching the web"

DECISION MATRIX — QUICK REFERENCE
────────────────────────────────────────────────────────────────────────────────

When Claude's Artifact 2 isn't prescriptive enough, use these defaults:

┌──────────────────────┬────────────────────────────────────────────────────┐
│ Setting              │ Default Recommendation                             │
├──────────────────────┼────────────────────────────────────────────────────┤
│ Format               │ Presentation (most common use case)               │
│ Text Mode            │ Preserve (Claude already optimized)               │
│ Text Amount          │ Detailed (balanced, professional)                 │
│ Theme                │ Basic Light (safe, universal)                     │
│ Image Source         │ AI images (Claude provided prompts)               │

│ Card Count           │ 20 (fits most presentations)                      │
└──────────────────────┴────────────────────────────────────────────────────┘


WHEN TO DEVIATE FROM DEFAULTS:
• Claude explicitly recommends different settings → Follow Claude
• Your content is highly visual → Select "Colorful" or "Abstract" style
• Corporate/formal context → Use "Title" or "Stratos" theme
• Text-heavy report → Select "Document" format, "Extensive" text amount
• Creative/marketing → Use "Aurora" or "Prism" theme, "Colorful" style

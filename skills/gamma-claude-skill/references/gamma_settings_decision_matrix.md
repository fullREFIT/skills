QUESTION: How many cards should I generate?

CONSTRAINTS BY TIER:
┌──────────────┬──────────────────────────────────────────────────────────┐
│ Free         │ Max 10 cards per generation                              │
│ Plus         │ Max 20 cards per generation                              │
│ Pro          │ Max 60 cards per generation                              │
│ Ultra        │ Max 75 cards per generation                              │
└──────────────┴──────────────────────────────────────────────────────────┘

RECOMMENDED COUNTS BY USE CASE:
┌─────────────────────────────┬────────────────────────────────────────┐
│ Use Case                    │ Card Count                             │
├─────────────────────────────┼────────────────────────────────────────┤
│ Elevator pitch              │ 5-8 cards                              │
│ Short presentation          │ 10-15 cards                            │
│ Standard pitch deck         │ 15-20 cards                            │
│ Detailed presentation       │ 25-35 cards                            │
│ Training/workshop           │ 30-45 cards                            │
│ Comprehensive report        │ 40-60 cards                            │
│ Technical documentation     │ 50-75 cards                            │
└─────────────────────────────┴────────────────────────────────────────┘

DECISION FACTORS:
• How long is your content? (1 page ≈ 2-3 cards)
• Presentation time? (1 minute ≈ 1-2 cards)
• Text density? (More text = fewer cards needed)
• Your tier limit? (Don't exceed max)

RULE OF THUMB: Start conservative, add cards manually later if needed

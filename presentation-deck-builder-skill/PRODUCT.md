# Product context

## Product
Presentation Deck Builder v2 is an open-source agent skill and renderer for turning structured research into branded, keyboard-navigable presentation websites.

## Audience
- AI-assisted operators who need to turn reports into presentations
- Consultants and internal teams managing more than one brand
- Claude, Codex, Cursor, and other agent users who can run bundled scripts
- Developers who want a validated JSON-to-presentation workflow

## Primary job
Choose a built-in or custom brand, apply it to a structured report, and produce a validated presentation website without editing the original renderer.

## Primary action
Download the skill or open the GitHub repository.

## Proof
- Four built-in brand profiles
- A first-class custom-brand contract
- An isolated renderer for every build
- JSON schema validation and content budgets
- TypeScript tests and production builds
- No credentials or private filesystem dependency

## Non-goals
- PowerPoint or Keynote export
- WYSIWYG slide editing
- Hosting customer data
- A hosted deck-generation service

## Register
Marketing landing page plus open-source documentation.

## Platform
web

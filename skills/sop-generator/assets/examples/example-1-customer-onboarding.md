# Example 1: Customer Onboarding SOP

## Context

- **Process:** New customer onboarding from signup to kickoff call
- **Source:** 5-minute screen recording transcript
- **Company type:** B2B SaaS
- **Complexity:** Medium (9 steps, 3 decision points, parallel awareness needed for partner referrals)

## Why This Example Matters

This example shows how the SOP Generator handles:
1. A linear process with conditional branches (partner referral check, timezone handling)
2. Multiple tools and systems involved (Stripe, admin panel, Calendly, Google Drive)
3. Time-sensitive requirements (24-hour partner credit window, 48-hour kickoff scheduling)
4. Common errors that are easy to prevent with documentation

See SKILL.md for the full source transcript and complete generated SOP.

## Key Features Demonstrated

- **Decision trees at Steps 1, 4, and 5** — Payment verification, partner referral check, and timezone handling each have exhaustive branching
- **Error handling table** — Four specific errors with causes, fixes, and prevention
- **Time estimates per step** — Total of ~60 minutes spread across 48 hours
- **Success criteria checklist** — 9 verifiable items the process owner can check
- **Escalation paths** — Clear contacts for each type of exception

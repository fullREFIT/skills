# Custom brand intake

Accept any combination of a style guide, logo, public website, palette, font names, existing deck, or plain-English description.

Normalize the evidence into brand name, text wordmark, optional tagline, ten functional color roles, three font roles, and three to seven visual rules. Preserve provenance for extracted facts.

Show the user the compact result and a recommended interpretation. Do not ask them to approve code.

If no primary color is available, ask for one preferred accent or permission to propose one. If no font is available, recommend an accessible pairing and label it as a proposal. If no wordmark is available, use the verified brand name as plain text. Never invent a logo.

Prefer the latest dated style guide over an older website. Show unresolved conflicts instead of merging them silently.

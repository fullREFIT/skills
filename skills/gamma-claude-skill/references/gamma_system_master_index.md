COMMON ISSUES & QUICK FIXES:
────────────────────────────────────────────────────────────────────────────

Issue: Output too long for my Gamma tier
Fix: In next iteration, specify: "Condense to [X] cards for [Tier] plan"

Issue: Tone isn't right
Fix: Be more specific about tone: not "professional" but "confident,
     data-driven, slightly informal"

Issue: Missing critical content
Fix: Verify it was in your prompt. If yes, reiterate: "MUST include [X]"

Issue: Image prompts too generic
Fix: Provide style reference: "Image style should match [company/brand]"

Issue: Settings don't match my Gamma UI
Fix: Gamma evolves. Ask Claude: "Search for current Gamma UI, update settings"

Issue: Overwhelmed by optimization guide
Fix: Start with just Section I (settings), ignore rest until after first
     generation

HOW TO UPDATE:
────────────────────────────────────────────────────────────────────────────

1. Test current setup with new project first
2. Identify specific improvement needed
3. Read gamma_project_prompt_improved.md to understand architecture
4. Edit gamma_project_custom_instructions.txt (make small changes)
5. Test change with simple project
6. If works, keep. If breaks, revert.
7. Document your change (add comment in instructions)


VERSION CONTROL:
────────────────────────────────────────────────────────────────────────────

Good practice:
• Keep original files backed up
• Date your modifications: "Modified 2026-01-15: Added X"
• Test modified version in separate project first
• Revert quickly if changes cause issues


STAYING CURRENT WITH GAMMA:
────────────────────────────────────────────────────────────────────────────

The custom instructions include mandatory web search protocol:
→ Claude automatically searches current Gamma docs before recommending
→ This keeps recommendations current even as Gamma evolves
→ You don't need to update instructions for every small Gamma change

# trafilatura-research

Source: https://github.com/adbar/trafilatura
Docs: https://trafilatura.readthedocs.io/
License: Apache-2.0

## Purpose

Use Trafilatura for fast extraction of clean article text, metadata, and Markdown from web pages. Best for research corpora, article cleanup, and preparing sources for summaries or retrieval.

## Installed targets

- Hermes: `~/.hermes/skills/research/trafilatura-research/`
- Codex: `~/.codex/skills/trafilatura-research/`
- Antigravity: `~/.antigravity/skills/trafilatura-research/`
- Cursor: `~/.cursor/skills/trafilatura-research/`
- Collection: `~/.claude/skills/trafilatura-research/`

## Notes

This package is a skill wrapper, not a vendored copy of the full upstream repository. Install any runtime package or configure API endpoints only when a task actually needs live extraction.
